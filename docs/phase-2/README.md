# Phase 2 — Tenant & School Core (Detailed)

## Objective

Build the SaaS foundation for the School Management System by defining the tenant domain, school configuration, academic sessions, tenant context, database design, API contracts, validation rules, and testing strategy.

This phase intentionally stops before Authentication (Phase 3), but every decision is made so Phase 3 can be implemented without changing the architecture.

## Deliverables

- Tenant architecture
- Tenant domain model
- School configuration model
- Academic Session model
- Tenant context design
- Tenant isolation strategy
- PostgreSQL database design
- Prisma modeling guidelines
- REST API contracts
- Validation rules
- Testing strategy
- Completion checklist

## Phase Dependencies

- Phase 0: Architecture & Rules
- Phase 1: Backend Foundation
